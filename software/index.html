    Programari, Bases de Dades i altres Eines

    Programari i bases de dades

    Obtenció de seqüències
    • NCBI & UniProt — bases de dades de proteïnes utilitzades per obtenir seqüències genèriques i termoestables
    Agrupament
    • CD-HIT — agrupa seqüències per similitud per reduir la redundància dins dels datasets
    Alineament
    • MAFFT — eina d’alineament múltiple de seqüències
    Retall
    • trimAl — elimina regions mal alineades de l’MSA
    Estructura i Accessibilitat al Solvent
    • FreeSASA — calcula l’àrea de superfície accessible al solvent
    • ChimeraX — visualització molecular i anàlisi estructural
    Anàlisi de Conservació
    • goalign — manipulació d’MSA i extracció de PSSM

    Anàlisi estadística - Python

    Es van utilitzar scripts de Python personalitzats per a les anàlisis estadístiques i la divergència KL. Els paquets utilitzats van ser:

    • NumPy — operacions numèriques i manipulació de matrius
    • pandas — càrrega i manipulació de dades tabulars
    • SciPy — tests estadístics (Chi-quadrat, Fisher exacte, Mann-Whitney U, T-test, divergència KL)
